# Living World

**We create the conditions. The people create the world.**

An Android-first Godot prototype for an autonomous living-world simulation.

The design target is a vast, causally consistent world with exactly 100 founders, autonomous descendants, natural ecosystems, and a Pure Observation mode. Physical rules matter: sticks cannot break rocks.

The first playable milestone will add a generated landscape, founder agents, time controls, and a mobile-friendly interface. This is a foundation, not the complete simulation.

## Godot
Import `project.godot` in Godot 4.x to open the project.
